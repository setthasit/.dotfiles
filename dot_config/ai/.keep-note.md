# Canonical agent policy

`AGENTS.md` in this directory is the single source of truth for every coding agent on
this machine. chezmoi symlinks it to each host:

| Symlink | Agent |
|---|---|
| `~/.omp/agent/AGENTS.md` | oh-my-pi |
| `~/.config/opencode/AGENTS.md` | opencode |
| `~/.codex/AGENTS.md` | Codex CLI |
| `~/.claude/CLAUDE.md` | Claude Code |

Edit `~/.config/ai/AGENTS.md` only. Never edit a symlink target's copy — there are no copies.
